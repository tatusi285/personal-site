01 — 关于

工作方向

工作分两条线。桌面集成线处理「合成层已被系统接管」这一约束：在 DirectComposition 之上定位宿主窗口、 用 CreateSwapChainForHwnd 挂接 D3D11 交换链、把渲染循环与 UI 线程解耦，并处理全屏检测、帧率控制与资源回收。 已落地的成果包括动态壁纸与屏保（Haloflux）、磁盘盘点工具（disk-keeper）与 DSH 维护脚本。

本地 AI 线处理「推理如何变成服务」：集中管理模型、参考音频与启动参数，对外暴露稳定接口， 并把执行状态经消息通道送到移动端。研究方面，围绕记忆冲突的可判定性完成 37 组条件、约 5.1 万次查询的受控实验， 整理为论文与可复现仓库。

01 桌面集成

Haloflux

Windows 11 的桌面由 DirectComposition 合成，常规 GDI 绘制会被丢弃。实现先定位 Explorer 的桌面宿主窗口， 再以 CreateSwapChainForHwnd 将 D3D11 交换链挂到该 HWND 由 GPU 呈现；渲染循环独立于 UI 线程， 并处理全屏检测、帧率控制与资源回收。屏保复用同一渲染核心，叠加多层断环 HUD、八块扇形数据面板与音乐可视化。 仓库 29 次提交。

  • C# / .NET 9
  • D3D11

02 研究

记忆冲突的可判定性

受控实验：记忆槽同时保有陈旧值与更新值，考察智能体是否取用当前值。37 组条件、约 51,000 次查询、4 种模型配置。 结论与主流假设相反——决定答案的不是维护策略（时效、重要性、衰减），而是呈现层面的可判定性： 时间戳可靠时陈旧记录基本被消除（≤0.2%）；去掉时间戳后，仅改变记录顺序即可令错误率在 0%–100% 之间翻转， 方向依模型而异。据此构造的记忆层在端到端任务上达到 100% 正确率。

  • Python
  • 受控实验
  • LLM 记忆

03 工具链

disk-keeper

只读优先的磁盘盘点工具。扫描 C、D、E 三盘目录树，按大小与时间戳生成大文件与当日新增清单， 结合扩展名、路径特征与安装规则标注用途和风险，分总览、大文件、今日新增、冗余、清理箱五个视图。 实测一次快速扫描 1.4 分钟，三盘索引覆盖 56% / 98% / 100%。

其他原型

  1. dsh-pet

    置顶透明窗口的桌面智能体入口。后端接入会话与工具集，语音侧调用本地 GPT-SoVITS 运行时， 能力覆盖文件读取、网页检索、屏幕观察与 Office 文档生成；指令可由 QQ 私聊触发。

  2. piano-keys

    将《Avid》键盘谱解析为时间序列并映射到 E3–D5 共 23 键，以键帽填充作倒计时； 实时判定按键并统计连击与准确率，设五档难度与自动演奏核对。

  3. qq-dsh-bridge

    读取会话状态与任务结果，经 QQ 协议投递到指定会话，并提供 AstrBot 插件； 只读定位，不做远程控制。

另有 emb-server（本地 embedding HTTP 服务）、原神知识库三件套（原始数据到 Markdown 检索语料）、 pilot（提示词对照实验）、daml（分层记忆验证）、astrbot-manual（插件手册静态生成）、 DSH 桌面入口原型、WSL + RVC 语音转换原型与技术交底书，均记录在项目集文档中。
