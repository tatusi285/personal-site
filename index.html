01 — 关于

我做的是什么

我是成都工业学院 2024 级软件工程的学生。比起按部就班完成作业，我更习惯给自己找一些 “系统本来没打算给你”的问题：让视频活到桌面图标背后，让本地语音模型常驻成一只桌宠， 让会话进度出现在手机 QQ 上。

做这些的方式基本固定：先确认链路卡在哪，再写一个能跑通的最小版本， 然后补上目录、启动脚本与 README，让下一次还能重来。卡住的时候就去翻驱动文档和别人的踩坑记录。

精选项目

01 桌面集成

Haloflux

Windows 11 的动态壁纸与屏保。画面挂在桌面图标之后：用 Win32 定位 Explorer 的宿主窗口， 用 CreateSwapChainForHwnd 把 D3D11 交换链挂到宿主窗口上，渲染循环与 UI 线程分离。屏保复用同一核心， 叠多层断环 HUD、扇形数据面板与音乐可视化。

  • C# / .NET 9
  • D3D11
  • Win32

02 本地 AI

dsh-pet 桌宠

常驻桌面的智能体入口。置顶透明窗口承载角色与对话，后端接会话与工具：语音走本地 GPT-SoVITS 克隆音色，能力覆盖文件读取、网页检索、屏幕观察与 PPT / Word 生成，指令也能从手机 QQ 私聊发进来。

  • Python
  • GPT-SoVITS
  • DSH

03 前端 / 交互

piano-keys

把《Avid》的键盘谱做成可视化练习器。谱面解析成时间序列后映射到 23 个按键，每个音符提前点亮键帽、 填满即到演奏时点；实时判定按键并统计分数、连击与准确率，五档难度按音域与和弦裁剪。

  • JavaScript
  • 音频时序
  • 实时判定
本地项目 · 未开源
04 工具链

disk-keeper

只读优先的系统盘盘点工具。扫描 C、D、E 三盘目录树，按大小与时间戳列出大文件和当日新增， 再结合扩展名与安装规则标注用途和风险，并把结果分成总览、大文件、今日新增、冗余与清理箱几个视图。

  • C# / .NET
  • 文件系统
  • 规则标注
本地项目 · 未开源
05 本地 AI

qq-dsh-bridge

在手机 QQ 上只读查看会话进度，任务完成时自动推送。桥接程序读取会话状态与任务结果， 经 QQ 协议投递到指定会话；另封装成 AstrBot 插件，提供查询与推送指令。

  • Python
  • QQ 协议
  • AstrBot
